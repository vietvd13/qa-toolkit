Bắt đầu kiểm thử API

Dán một request từ Postman hoặc DevTools, gửi thử ngay, rồi lưu vào collection để chạy lại bất cứ lúc nào. Không cần tạo collection hay environment trước.

· phím ? mở hướng dẫn ở bất kỳ đâu

Dữ liệu chỉ lưu trên máy này. Token / password chỉ giữ trong phiên trình duyệt.

draft Chưa lưu

Request không có body. Chọn JSON, Text, XML hoặc x-www-form-urlencoded để thêm. multipart/form-data (upload file) chưa hỗ trợ.

Giống Pre-request / Post-response Script của Postman. Chạy trong sandbox, không có mạng trừ pm.sendRequest tới Allowed hosts. Không bắt buộc.

Tab thụt lề · Esc rồi Tab để rời ô · Dùng pm.environment.get('TOKEN'), đừng ghi token vào script.
